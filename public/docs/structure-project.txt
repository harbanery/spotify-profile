CATATAN PENEMPATAN
------------------
- src/types/ (global) sengaja tidak dibuat: setelah models/ di-takeout,
  SEMUA interface tersisa terbukti domain-spesifik sehingga lebih tepat
  di features/*/types.ts (User → web, FormLayout → admin). Buat src/types/
  hanya saat muncul interface yang dipakai lintas feature.
- components/layout/ (global) belum ada isinya — layout admin & web hidup
  di features/*/components/layout. Tidak membuat folder kosong.

ATURAN PENEMPATAN (ringkas)
---------------------------
1. app/            → hanya routing/layout/page/route handler; logika domain
                     didelegasi ke services/utils/server. Feature module
                     halaman: section/ (web), decorator/ + config/ (admin)
                     di DALAM folder routenya.
2. components/     → hanya UI/konfigurasi global (i18n, ui). UI spesifik
                     satu domain → features/<domain>/components.
3. features/<d>/   → components/ui (UI domain), components/layout (shell),
                     hooks/ (store/hook domain, mis. session), utils/
                     (helper domain), types.ts (tipe domain).
4. lib/            → client integrasi pihak ketiga yang memegang secret
                     (Midtrans, Cloudinary, SMTP) + auth/otp. Dilarang
                     di-import komponen client murni.
5. services/       → semua query Prisma + caching data publik. Nama file
                     = domain (blog.ts, order.ts) tanpa suffix "Service".
6. utils/          → config/ (env), helpers/ (fungsi murni, satu index.ts),
                     server/ (modul server-side), email/, pdf/, fonts/.
7. hooks/          → hook React global.
8. Konvensi antd + Tailwind: className Tailwind pada komponen antd wajib
   diakhiri "!" (important) atau dibungkus div — style antd lebih spesifik.
9. Navigasi        → useRouter (next/navigation), bukan <Link> next/link.

Pemetaan ke blueprint umum (structure-project.txt):
  app/        → app/ (sama, tidak berubah)
  components/ → components/ (ui, i18n) + hooks/ + features/*/components
  features/   → features/admin + features/web (components, utils, types)
  services/   → services/ (data access)
  lib/        → lib/ (midtrans, cloudinary, email) + utils/server (db, cache)
  types/      → features/*/types.ts (domain) — src/types bila ada yang global
  utils/      → utils/ (config, helpers, email, pdf)
